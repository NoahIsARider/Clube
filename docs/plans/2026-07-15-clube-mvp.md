# Clube MVP Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 构建一个可部署到 Vercel 或 GitHub Pages 的 Clube Web MVP，覆盖组织创建、成员加入、排片发布、报名、匿名反馈、影评发布与数据导出。

**Architecture:** 采用 `React + Vite + TypeScript + React Router` 构建前端单页应用，直接连接 Supabase 完成鉴权、数据持久化与文件/图片存储。为了降低首次接入门槛，前端提供 `demo mode` 回退机制：未配置 Supabase 环境变量时仍可本地启动并浏览完整界面与主要交互流，但不会保存真实数据。

**Tech Stack:** React 19, Vite, TypeScript, React Router, Supabase JS, TanStack Query, Zustand, Tailwind CSS, Vitest, Testing Library, PapaParse

---

## 产品范围

### 角色设计
- 平台用户可以创建组织，创建者默认成为该组织管理员。
- 管理员可转移管理员身份给其他成员。
- 用户可通过组织审核流程或邀请码加入组织。
- 组织成员分为管理员、干事、普通成员。

### 核心流程
1. 创建组织并生成邀请码。
2. 管理员审核加入申请或通过邀请码拉新。
3. 干事发起排片，填写片名、时间、场地、海报、简介。
4. 管理员或干事发布活动预告。
5. 普通成员报名参与。
6. 活动结束后提交匿名评分与短评。
7. 管理员导出活动报名、签到、反馈与影评数据。

### MVP 页面
- 首页
- 登录 / 体验入口
- 组织选择与创建页
- 组织控制台
- 排片日历
- 活动详情页
- 匿名反馈页
- 影评与公告流
- 数据导出页

### organizations
- `id`
- `name`
- `slug`
- `description`
- `invite_code`
- `owner_user_id`
- `created_at`

### organization_members
- `id`
- `organization_id`
- `user_id`
- `role` (`admin` / `staff` / `member`)
- `join_method` (`approval` / `invite`)
- `status` (`pending` / `approved`)

### screenings
- `id`
- `organization_id`
- `title`
- `subtitle`
- `venue`
- `starts_at`
- `capacity`
- `poster_url`
- `status` (`draft` / `published` / `closed`)

### registrations
- `id`
- `screening_id`
- `user_id`
- `status` (`registered` / `checked_in` / `cancelled`)

### feedback_entries
- `id`
- `screening_id`
- `rating`
- `comment`
- `created_at`

### posts
- `id`
- `organization_id`
- `screening_id`
- `type` (`review` / `notice`)
- `title`
- `content`
- `author_user_id`
